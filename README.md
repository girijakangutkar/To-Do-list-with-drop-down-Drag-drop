# Task Organizer App

A React-based task management application that allows users to create tasks with a title and description, and organize them across multiple workflow sections. Tasks are initially added to the backlog and can be reassigned via dropdown selection or manual drag-and-drop between sections.

## Features

- Task creation with title and description input
- Backlog section for newly added tasks
- Dropdown menu to assign tasks to specific sections
- Drag-and-drop functionality for manual task movement
- Responsive layout for desktop and mobile
- Modular component structure for scalability

## Tech Stack

- React
- CSS
- React DnD or similar drag-and-drop library
